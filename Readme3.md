# Digital Literacy and English Education
### Fall 2026 Course Syllabus | 15 Weeks

---

## Course Description

This course builds practical digital literacy skills for future EFL/ESL English teachers through hands-on creation. Over the semester, you will learn basic Python programming, basic HTML, and how to turn a working script into a deployed web application using Streamlit. Every skill you learn is applied directly to language-teaching materials — vocabulary tools, text tools, simple course webpages — building toward a final project: a deployed, working application designed for English language learners.

Along the way, you will also engage with a small set of core readings from established journals in digital literacy and language education, and examine critical questions about AI tools, information literacy, and digital equity in language classrooms.

You do not need any prior programming or web design experience for this course.

## Course Goals

By the end of this course, you will be able to:

1. Explain and critically discuss core concepts in digital literacy, including multiliteracies, AI tools in language education, information literacy, and digital equity.
2. Write basic Python scripts — variables, control flow, functions, and text/string processing — applied to language-teaching materials.
3. Build a basic webpage using HTML and simple CSS styling.
4. Turn a Python script into an interactive, deployed web application using Streamlit.
5. Work effectively in a small team to design, build, test, and present a functioning application.

Across all of these, you will be developing **computational thinking** — the ability to break a problem into parts, spot patterns, and design step-by-step solutions. This isn't taught as a separate topic; it's the thread running underneath every coding week, and you'll notice it becoming more natural as the course goes on.

## Group & Project Structure

- You will be placed into **teams of 4** for the semester.
- **Mini-Project (Week 8-10):** within your team of 4, you will split into **two pairs**. Each pair builds a small Python tool independently and presents it to the class.
- **Final Project (Weeks 12–15):** your full team of 4 comes back together, combining and building on what each pair created in the mini-project into one larger, deployed application, presented with a group reflection essay.

This structure means the final project isn't started from scratch — it grows out of work you've already done and tested earlier in the semester.

## Weekly Schedule

The pacing below is approximate. Topics are listed in the order they build on each other, but the exact boundary between weeks (e.g., exactly how much Python is covered by Week 4 versus Week 5) is left to your discretion as the course runs.

| Week | Topic | Focus | Reading |
|---|---|---|---|
| 1 | Course Introduction & Platform Setup | Course overview; team assignments; introduce and set up accounts for GitHub, Google Colab, Markdown, and Streamlit; set up each team's shared workspace (e.g., a GitHub repo per team) for later collaboration; preview the final project | Mishra & Koehler (2006) |
| 2 | AI Tools in English Education | Critical and ethical use of AI writing tools and chatbots in language learning; prompt literacy | UNESCO (2024) — Chapter 1, Chapter 2, and the "Acquire" level table in Chapter 4.1 |
| 3 | Information Literacy & Digital Equity | Evaluating online sources; the digital divide in language-learning contexts | Warschauer (2002) |
| 4–5 | Python Basics | Variables, data types, input/output, conditionals, and loops, practiced through short exercises relevant to language-teaching materials | — |
| 6 | Python & Text | Strings, lists, and reading/writing files, applied to a text-based exercise (e.g., working with a reading passage) | Coiro & Dobler (2007) |
| 7 | Functions & Code Organization | Organizing code into reusable functions, building on earlier exercises | Wing (2006) |
| 8 | Midterm Exam | Written test on digital literacy knowledge (Weeks 1–7) | — |
| 9 | Mini-Project: Build & Present | Within your team of 4, split into pairs; design, build, and present a small Python tool | — |
| 10–11 | HTML Basics | Structure, tags, and basic CSS styling — building a simple webpage | — |
| 12–13 | Streamlit | Turning a Python script into a running, interactive web app; deployment; teams begin combining pair scripts into one project | — |
| 14 | Final Project Build & Polish | In-class work time: debugging, UI polish, deployment via Streamlit Community Cloud | — |
| 15 | Final Presentations | Each team demos their deployed application and submits a group reflection essay | UNESCO (2024) — revisit the "Acquire" level table from Week 2 |

## Assessment Plan

| Component | Weight |
|---|---|
| Attendance & Class Participation | 10% |

### Assignments (30%) — Breakdown

| Assignment | Weight | Description |
|---|---|---|
| Reflection Log | 5% | Short, ongoing entries across the coding weeks — what you built, what broke, how you fixed it |
| Coding Assignments (with revision) | 15% | Weekly Python and HTML exercises, submitted in draft form and revised after feedback |
| Mini-Project | 10% | The pair-built Python tool from Week 9, including its in-class presentation |

### Final (30%) — Breakdown

| Component | Description |
|---|---|
| Deployed Application | The team's working Streamlit application, combining and extending both pairs' mini-projects |
| Presentation | A live demo of the deployed application in Week 15 |
| Reflection Essay | An individual or team essay reflecting on the design process, challenges, and what you'd improve — you may draw on the "Acquire / Deepen / Create" progression from UNESCO (2024) to describe your own growth over the semester |
