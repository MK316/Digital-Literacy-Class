# Digital Literacy & App Development Vocabulary

This file is both a human-readable vocabulary list and the data source used by the Streamlit flashcard app.
Each entry contains a keyword, an explanation, a quiz prompt, and any accepted alternative answers.

## Set 1 · Digital Foundations

### 001. Hardware

**Explanation:** The physical parts of a computer or digital device that you can touch, such as the screen, keyboard, processor, and storage device. These parts work together with software, which provides the instructions.

**Quiz prompt:** Which term refers to the physical components of a digital device that you can touch?

**Accepted answers:** —

---

### 002. Software

**Explanation:** The programs and instructions that run on a digital device. Applications, operating systems, browsers, and games are examples, and unlike physical components, these instructions are not tangible.

**Quiz prompt:** Which term refers to the non-physical programs and instructions that run on a digital device?

**Accepted answers:** —

---

### 003. OS

**Explanation:** OS stands for Operating System, the main software layer that manages a device and coordinates other programs with its hardware. Windows, macOS, iOS, and Android are common examples.

**Quiz prompt:** Which short term names the main software layer that manages a device and supports other programs?

**Accepted answers:** Operating System

---

### 004. Processor

**Explanation:** The component that carries out instructions and calculations inside a computer. It is also called the CPU, or Central Processing Unit, and it strongly affects how quickly many tasks can be performed.

**Quiz prompt:** Which term names the computer component that carries out instructions and calculations?

**Accepted answers:** CPU

---

### 005. Memory

**Explanation:** Temporary working space, usually RAM, that holds information while programs are running. Its contents are generally lost when the device is turned off.

**Quiz prompt:** Which term refers to temporary working space that holds information while programs are running?

**Accepted answers:** RAM

---

### 006. Storage

**Explanation:** Long-term space that keeps files and data on devices such as SSDs or hard drives. Unlike temporary working memory, the information remains available after the device is turned off.

**Quiz prompt:** Which term refers to long-term space that keeps files even after a device is turned off?

**Accepted answers:** —

---

### 007. Format

**Explanation:** The way information is organized inside a file. PDF, JPEG, CSV, DOCX, and MP3 are examples, and a file extension often indicates this organization.

**Quiz prompt:** Which term describes the way information is organized inside a file, such as PDF, JPEG, or CSV?

**Accepted answers:** File Format

---

### 008. Path

**Explanation:** The location of a file or folder inside a computer system. It is often called a file path and is needed when code must locate images, documents, or datasets.

**Quiz prompt:** Which term refers to the address-like location of a file or folder inside a computer system?

**Accepted answers:** File Path

---

### 009. Directory

**Explanation:** A location used to organize files and other directories. In everyday computer use, it is usually called a folder, while the technical term is common in programming and command-line environments.

**Quiz prompt:** Which term is the technical name for a folder used to organize files and subfolders?

**Accepted answers:** Folder

---

### 010. Cloud

**Explanation:** Remote computing resources that provide storage, processing, or software through the internet. Services such as Google Drive let users work with resources that are not stored only on their own device.

**Quiz prompt:** Which term refers to using remote computers over the internet for storage, processing, or software?

**Accepted answers:** Cloud Computing

---

### 011. Network

**Explanation:** A group of computers or devices that can communicate with one another. A home Wi-Fi setup is a small example, while the internet connects many such groups around the world.

**Quiz prompt:** Which term describes a group of connected devices that can communicate with one another?

**Accepted answers:** —

---

### 012. Internet

**Explanation:** The global infrastructure that connects computers and digital devices. It supports many services, including the Web, email, cloud storage, and online communication.

**Quiz prompt:** Which term refers to the global infrastructure that connects computers and digital devices worldwide?

**Accepted answers:** —

---

### 013. Web

**Explanation:** Short for the World Wide Web, a system of linked pages and resources accessed through the internet. It is one service that uses the internet, not the internet itself.

**Quiz prompt:** Which term refers to the system of linked pages and resources accessed through the internet?

**Accepted answers:** World Wide Web

---

### 014. Browser

**Explanation:** Software used to retrieve and display content from the Web. Chrome, Safari, Firefox, and Edge are examples, and this should not be confused with a search engine.

**Quiz prompt:** Which term names software such as Chrome, Safari, Firefox, or Edge that displays web content?

**Accepted answers:** —

---

### 015. Server

**Explanation:** A computer or software system that provides information or services when another device requests them. Websites commonly depend on this kind of system to deliver pages and data.

**Quiz prompt:** Which term refers to a computer or program that provides data or services to requesting devices?

**Accepted answers:** —

---

### 016. Client

**Explanation:** A device or program that requests information or services from another system. A web browser plays this role when it asks a remote computer for a webpage.

**Quiz prompt:** Which term refers to the device or program that requests data or services from another system?

**Accepted answers:** —

---

### 017. Domain

**Explanation:** A human-readable name used to identify an internet location, such as example.com. More formally called a domain name, it is easier to remember than a numerical network address.

**Quiz prompt:** Which term refers to a human-readable internet name such as example.com?

**Accepted answers:** Domain Name

---

### 018. URL

**Explanation:** An address that identifies a specific resource on the Web. URL stands for Uniform Resource Locator and can point to a page, image, document, video, or other online resource.

**Quiz prompt:** Which abbreviation refers to the web address of a specific online resource?

**Accepted answers:** Uniform Resource Locator

---

### 019. Webpage

**Explanation:** A single document or page available on the Web. A larger site usually contains many of these, and each one generally has its own address.

**Quiz prompt:** Which term refers to one individual page or document within a larger site on the Web?

**Accepted answers:** Web Page

---

### 020. Website

**Explanation:** A collection of related pages available under the same domain. A university site, for example, may contain separate pages for departments, courses, admissions, and research.

**Quiz prompt:** Which term refers to a collection of related web pages under one domain?

**Accepted answers:** —

## Set 3 · App Development & Git

### 041. Function

**Explanation:** A reusable block of code designed to perform a particular task. It can receive information, process it, and return a result, helping developers avoid repeated code.

**Quiz prompt:** Which term refers to a reusable block of code designed to perform a specific task?

**Explanation:** A structure that lets a program behave differently depending on whether a condition is true or false. In Python, it is commonly implemented with if, elif, and else.

**Accepted answers:** —

**Explanation:** A structure that repeats an operation. A program might use one to present several quiz questions or process every item in a collection.

**Quiz prompt:** Which term refers to a programming structure that repeats an operation?

**Accepted answers:** —

---

### 044. Bug

**Explanation:** A problem in software that causes incorrect or unexpected behavior. Some problems stop a program completely, while others allow it to run but produce the wrong result.

**Quiz prompt:** Which term refers to a problem in software that causes unexpected or incorrect behavior?

**Accepted answers:** Error

---

### 045. Debugging

**Explanation:** The process of locating, understanding, and fixing problems in code. It often involves reading error messages, testing small parts of a program, and checking assumptions.

**Quiz prompt:** Which term refers to the process of finding and fixing problems in code?

**Accepted answers:** —

### 046. Library

**Explanation:** A collection of reusable code created to support particular tasks. Developers can use such resources instead of building every feature from the beginning; the word package is sometimes used similarly.

### 047. API

**Explanation:** A defined way for one software system to communicate with another. API stands for Application Programming Interface, and apps may use one to request translation, speech processing, or AI-generated content.

**Accepted answers:** Application Programming Interface

### 048. Interface

**Accepted answers:** UI; User Interface

**Accepted answers:** —
