
# Week 02: Individual AI-Assisted Design Task | Guidelines
### AI 활용 영어학습 활동/앱 설계 공통 안내문

## 1. Before You Start (시작하기 전에)
- **개인 작업**: 이 활동은 전 과정 개인별로 독립적으로 수행합니다 (Work independently).
- **AI 선택 및 시작**: 생성형 AI(ChatGPT, Gemini, Claude, Copilot 등) 중 하나를 선택하여 반드시 새로운 일반 채팅(New Chat)에서 시작합니다.
- **사용 금지**: 기존 대화창, Custom GPT, 사전 설정 Project/Workspace, 외부 웹사이트/추가 자료, 미리 준비한 프롬프트, 타인의 도움.

## 2. First Prompt (첫 번째 공통 프롬프트)
새 AI 채팅창에 아래 문장을 첫 번째 프롬프트로 그대로 복사하여 입력합니다. (모든 참가자 공통)

> For the rest of this chat, do not use an interactive preview as the main output. Whenever you create or revise an activity/app, always provide the complete, up-to-date code as a single, self-contained HTML file in one code block. Do not provide only the changed parts of the code.

> ※ 첫 응답을 확인한 후 배정된 개별 과업(Task 01/02/03)을 확인하고, 본인이 원하는 방식으로 자유롭게 진행하세요.

## 3. Your Task (과업 및 목표): One will be assigned (Task 1, Task 2, Task 3)
- **제공 정보**: Learner info (중 2 EFL, A2–B1), Short text, Six target expressions
- **최종 목표**: Create a browser-based English learning activity/app that helps the learners understand and appropriately use the six target expressions.
- The specific instructional design is your decision.

## 4. During the Task (과업 수행: 20분)
- **시간**: 20분 (완성된 앱 제작이 필수는 아님)
- **AI와 상호작용**: 결과물 채택, 수정, 재요청 자유
- **코딩 불필요**: 필요한 기술 작업은 AI에 전적으로 요청 가능
- **독립적 판단**: 진행 중 추가 안내는 제공되지 않으며, 본인이 적절하다고 생각하는 방식으로 진행합니다.

## 5. When Time Is Up (20분 종료 시)
- **STOP 즉시 중단**: 신호 즉시 모든 작업 중단
- **추가 작업 금지**: 새 메시지 전송, 코드 수정, 결과물 완성 금지
- **대화창 유지**: 프롬프트 확인을 위해 AI 대화창은 절대 닫지 않음
- **완성 여부 무관**: 20분 종료 시점의 상태가 최종 기록입니다.

## 6. What You Will Submit (제출 자료)
- [필수] 20분 종료 시점 활동/앱 결과 화면 스크린샷 (하단 안내 참조)
- [필수] 직후 성찰 설문 (본인 생각으로 작성, AI 질의 금지)
- [선택/있는 경우] 저장한 HTML 파일 또는 링크

> ※ 완성도 평가가 아니며, 시점 작업 상태 기록용입니다.

## 7. Screenshot Guidelines (스크린샷 촬영 및 캡처 방법)

**캡처 대상 화면 원칙:**
- 20분 종료 시점에 만들어진 활동/앱을 학습자가 실제로 보게 되는 화면으로 캡처해 주세요.
- 가능하면 HTML 파일을 웹브라우저에서 실행한 후, 학습자가 실제로 보게 되는 활동/앱 화면을 스크린샷으로 저장해 주세요.
- 활동/앱을 실행하지 못한 경우에는 20분 종료 시점에 가지고 있는 결과 화면(AI 대화창 내 코드 등)을 그대로 캡처해 주세요.

**OS별 캡처 단축키 및 저장:**
- **Windows**: `Windows + Shift + S` → 앱 화면 선택 → 저장 → 바탕화면 또는 다운로드 폴더에 PNG 파일로 저장
- **Mac**: `Command + Shift + 4` → 앱 화면 영역 선택 → 자동 저장된 PNG 파일을 바탕화면에서 확인
