# Nakata et al. (2021): 누적 평가가 영어 어휘 학습에 미치는 영향
### Effects of Distributed Retrieval Practice Over a Semester: Cumulative Tests as a Way to Facilitate Second Language Vocabulary Learning

Nakata, T., Tada, S., McLean, S., & Kim, Y. A. (2021). *TESOL Quarterly, 55*(1), 248–267.

**핵심 메시지: 어휘 시험은 학습 결과를 확인하는 평가 도구인 동시에 학습을 촉진하는 교수 도구이다. 최근 학습한 단어뿐 아니라 이전에 학습한 단어를 함께 출제하는 누적 평가(Cumulative Testing)는 장기적인 어휘 기억을 향상시킬 수 있다.**

## 1. 연구 목적과 방법

이 연구는 매주 새롭게 학습한 단어만 시험에 출제하는 방식과 이전에 학습한 단어까지 포함하는 누적 평가 방식의 효과를 비교하였다.

일본 대학생 72명이 참여했으며, 최종 분석에는 67명의 자료가 사용되었다.

- **학습 기간:** 9주 동안 어휘 학습 및 주간 평가 실시
- **학습 어휘:** 의학 및 약학 관련 영어 어휘 80개(분석에는 76개 사용)
- **비누적 평가 집단:** 직전 수업에서 학습한 어휘만 평가
- **누적 평가 집단:** 최근 학습한 어휘와 이전 수업에서 학습한 어휘를 함께 평가
- **최종 평가:** 마지막 주간 평가로부터 3주 후, 사전 예고 없이 수용적·산출적 어휘 지식 측정

두 집단 모두 매주 동일하게 10문항의 어휘 시험을 치렀다. 누적 평가 집단은 평균적으로 최근 학습 어휘 58%, 이전 학습 어휘 42%를 출제받았다. :chatgpt-content-reference{index="0"}

## 2. 주요 연구 결과

**첫째, 누적 평가 집단은 주간 시험에서 낮은 점수를 받았지만 최종 평가에서는 더 높은 성과를 보였다.**

| 평가 유형 | 비누적 평가 | 누적 평가 |
|---|---:|---:|
| 주간 시험 평균 | 85.0% | 73.1% |
| 최종 수용적 어휘 평가 | 26.4% | 50.9% |
| 최종 산출적 어휘 평가 | 12.1% | 38.5% |

누적 평가 집단은 매주 치르는 시험에서 상대적으로 낮은 성적을 보였다. 그러나 3주 후 실시한 최종 평가에서는 수용적·산출적 어휘 지식 모두에서 유의미하게 높은 점수를 기록하였다. :chatgpt-content-reference{index="1"}

**둘째, 누적 평가를 통해 더 큰 어휘 학습 향상이 나타났다.**

사전·사후검사의 점수 증가량을 기준으로 비교하면 누적 평가 집단의 학습 효과는 비누적 평가 집단보다 수용적 어휘에서 약 2.06배, 산출적 어휘에서 약 3.38배 높았다.

연구자들은 이러한 결과를 반복 인출, 학습 시간 증가, 분산 학습 등의 가능성으로 설명한다. 다만 실제 개인별 학습 시간이 통제되지 않았으므로 어떤 요인이 이러한 차이를 주도했는지는 확정할 수 없다. :chatgpt-content-reference{index="2"}

**셋째, 학습 과정에서 높은 점수가 반드시 장기적인 학습 성과를 의미하지는 않는다.**

최근 학습한 내용만 평가하면 당장의 시험 성적은 높아질 수 있다. 그러나 이전에 학습한 내용을 다시 떠올려야 하는 누적 평가는 학습 과정에서 더 어렵게 느껴지더라도 장기적인 기억에 도움이 될 수 있다.

이는 학습 과정에서 발생하는 적절한 어려움이 장기적인 학습 성과를 높일 수 있다는 *Desirable Difficulty* 개념과 연결된다. :chatgpt-content-reference{index="3"}

## 3. 예비 영어교사가 배워야 할 다섯 가지

| 핵심 학습 내용 | 영어 수업 설계에 주는 시사점 |
|---|---|
| **① 평가의 학습 기능** | 어휘 시험을 단순한 성적 측정 도구가 아니라 학습을 촉진하는 활동으로 활용한다. |
| **② 누적 평가의 중요성** | 매주 최근 학습한 단어와 이전에 학습한 단어를 함께 출제한다. |
| **③ 인출 연습의 활용** | 정답을 반복해서 읽기만 하기보다 기억에서 직접 떠올리는 활동을 포함한다. |
| **④ 장기적 학습 성과의 평가** | 주간 시험 성적뿐 아니라 일정 시간이 지난 후에도 어휘를 기억하는지 확인한다. |
| **⑤ 학습자의 동기 고려** | 누적 평가의 목적을 설명하고, 시험의 난도가 학습자의 자신감이나 동기를 떨어뜨리지 않도록 고려한다. |

특히 누적 평가에서는 학생이 이미 배운 단어도 시험에 다시 등장할 수 있다는 사실을 사전에 안내하는 것이 중요하다.

연구자들은 누적 시험의 낮은 점수가 일부 학습자의 동기에 부정적인 영향을 미칠 가능성도 지적한다. 따라서 평가 방식을 설계할 때 학습 효과뿐 아니라 학생의 정서적 반응도 고려해야 한다. :chatgpt-content-reference{index="4"}

### 수업 설계 사례: 누적 어휘 퀴즈

매주 새로운 어휘 10개를 학습하는 영어 수업을 가정해 보자.

| 주차 | 새로운 학습 어휘 | 퀴즈 구성 |
|---|---|---|
| 1주 | Set 1 | 새로운 어휘 학습 |
| 2주 | Set 2 | Set 1 평가 |
| 3주 | Set 3 | Set 2 + Set 1 평가 |
| 4주 | Set 4 | Set 3 + 이전 학습 어휘 평가 |
| 5주 | Set 5 | Set 4 + 이전 학습 어휘 평가 |

주간 퀴즈는 10문항으로 구성하고, 최근 학습 어휘 6문항과 이전 학습 어휘 4문항을 혼합할 수 있다.

또한 일부 문항은 영어 단어의 의미를 선택하도록 하고, 다른 문항은 주어진 의미에 해당하는 영어 단어를 직접 작성하도록 구성한다.

이는 연구에서 검증한 누적 평가의 원리를 적용한 수업 설계 사례이며, 모든 학습자에게 가장 효과적인 문항 비율이 확립되었다는 의미는 아니다.

## 4. 연구 결과를 해석할 때 주의할 점

이 연구에서 누적 평가 집단의 성과가 더 높았다고 해서 그 효과가 전적으로 분산 학습 때문이라고 단정할 수는 없다.

누적 평가 집단은 이전 어휘까지 시험 범위에 포함되었으므로 시험을 준비하는 데 더 많은 시간을 사용했을 가능성이 있다. 실제 학습 시간이나 학습 전략은 통제되지 않았다.

또한 집단 간 영어 능력의 동등성이 별도의 공인 영어 시험으로 확인되지 않았고, 누적 평가 집단에서는 일부 어휘가 주간 시험에 한 번도 출제되지 않았다. 이러한 요인들은 연구 결과를 해석할 때 고려해야 한다. :chatgpt-content-reference{index="5"}

## 5. 수업 토론 질문

**예비교사에게 던질 핵심 질문은 다음과 같다.**

1. 학생들이 매주 어휘 시험에서 높은 점수를 받지만 한 달 후 대부분을 잊어버린다면, 그 시험은 교육적으로 효과적이었다고 볼 수 있을까?
2. 누적 평가가 장기적인 기억에 도움이 되더라도 학생들에게 부담을 준다면 교사는 어떻게 평가 방식을 조정해야 할까?
3. 디지털 어휘 학습 앱을 개발한다면 이전에 학습한 어휘를 언제, 어떤 비율로 다시 출제하도록 설계하겠는가?

**결론:** 이 논문에서 예비교사가 얻어야 할 가장 중요한 교훈은 **평가를 학습과 분리된 활동으로 보지 않는 것**이다. 어휘 시험의 내용과 출제 방식을 조금만 변경해도 학습자가 복습하고 기억을 인출하는 방식이 달라질 수 있다. 따라서 영어교사는 당장의 시험 점수뿐 아니라 장기적인 기억과 학습자의 동기를 함께 고려하여 평가를 설계해야 한다.
